# 🕒 OLED Clock

A minimal, OLED-inspired digital clock with a clean dark interface, designed to bring a modern clock experience to the web.

🔗 **Live Demo:** [oled-clock.netlify.app](https://oled-clock.netlify.app/)

## ✨ Features

- 🕒 **Live Clock Display** — View the current time in a digital clock interface.
- 🌑 **OLED-Inspired Design** — A dark visual theme inspired by OLED displays.
- 🎨 **Minimal UI** — A clean, distraction-free interface focused on readability.
- 📱 **Responsive Design** — Designed for a convenient viewing experience across screen sizes.
- 🚀 **Live Deployment** — Accessible online through Netlify.
